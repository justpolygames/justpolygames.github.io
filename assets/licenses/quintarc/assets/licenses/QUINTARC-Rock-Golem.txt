QUINTARC adaptation: converted the supplied mesh, skin weights, UVs and native
animations to glTF; rebuilt legacy material connections using the packed original
diffuse texture; discarded the source camera, floor and separate thrown-rock prop.
Runtime sizing, material tint and sourced particle attachments create elemental
variants. Original source retained in incoming-assets/quintarc-rock-golem.blend.
Reproducible conversion: tools/import_golem_asset.py (Blender --disable-autoexec).

2026-09-29 correction: bake the source Mirror modifier before glTF conversion.
The earlier export contained only the editable half-mesh. The complete source
mesh has 1,795 vertices and 1,692 faces before glTF UV/normal splitting;

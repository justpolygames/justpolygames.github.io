Sages & inspiration

Wizard, Witch and Elven Sage use Quaternius’s Wizard, Witch and Elf from the Ultimate Animated Character Pack (2019), released under CC0. QUINTARC offers robe and trim colors, skin tones, hair colors where available, and original Sage hat, Horned helm, Tricorn or Crested helm, or no headgear; belts stay visible with four color choices. Existing characters keep their original Wizard selection. Original asset pack · License.

QUINTARC’s elemental invocation design is inspired by Invoker from Dota. QUINTARC is an independent game by Just Poly Games.

Spell icon artwork

Studio & website artwork

The JP emblem and wordmark are the original supplied Just Poly Games artwork, used unchanged in their bright colors. Project Pencil’s cover is existing studio artwork. The controller illustration is original CSS geometry for this portfolio.

The QUINTARC seal incorporates Open book by Lorc, CC BY 3.0, recolored and composed with five elemental orbs and symbols, surrounding rings, and a dark panel.

Visual inspiration: GitMastery. No reference website code or artwork was copied. Hosting: GitHub Pages.

Item and mob portraits are rendered from the games’ existing geometry and licensed source models. Project Pencil’s models and recipe shapes are original game artwork; QUINTARC portraits use the KayKit and Quaternius resources credited above. Hole uses its in-game recipe symbol because it has no standalone mesh.
